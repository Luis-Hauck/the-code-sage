# Referências (API interna do projeto)

Nesta seção você documenta “o que existe” no código: comandos, serviços, repositórios e modelos de dados. É útil para consulta rápida por quem já conhece a visão geral.

Recomendação: uma página por unidade de código que faça sentido ser reutilizada/consultada isoladamente.

## Índice sugerido
- Cogs/Comandos (Slash Commands)
- Serviços (Regras de negócio)
- Repositórios (Acesso a dados)
- Modelos de Dados (Entidades)

Você pode usar os modelos prontos em docs/modelos/ para criar novas páginas de referência.

## Onde começar
- Para um novo comando, copie docs/modelos/comando.md e preencha.
- Para um novo serviço, copie docs/modelos/servico.md.
- Para um repositório, use docs/modelos/repositorio.md.
- Para um modelo/entidade, use docs/modelos/modelo-de-dados.md.
