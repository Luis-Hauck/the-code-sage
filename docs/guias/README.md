# Guias (Tutoriais passo a passo)

Use esta seção para explicar tarefas com começo, meio e fim. Exemplos: instalar, configurar variáveis, realizar deploy, rodar seeds, etc.

Quando criar um novo guia, use o modelo abaixo como referência rápida.

---
# Título do Guia

Para quem é: descreva em 1–2 linhas o público-alvo e o que este guia resolve.

Pré‑requisitos
- Lista de ferramentas/versões necessárias (Python, Poetry, MongoDB, etc.)

Passo a passo
1. Passo 1 — o que fazer, por que e como validar
2. Passo 2 — comandos, arquivos editados, prints ou logs
3. Passo 3 — resultado esperado

Validação
- Como verificar que funcionou (comando, saída, tela no Discord, etc.)

Próximos passos
- Links para outras páginas úteis ou guias avançados
